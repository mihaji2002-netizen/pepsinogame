# Design System Master: PEPSINO LAB

## Direction

**Cinematic Signal Lab** — void hero, electric mint signal, hot orange pulse, massive Persian display type.

## Typography

- Display: **Changa** (Arabic/Persian, bold, tech)
- Body: **IBM Plex Sans Arabic**

## Colors

| Token | Hex | Use |
|------|-----|-----|
| `--void` | `#061416` | Hero / command surfaces |
| `--signal` | `#2FF5C2` | Energy / CTA / XP |
| `--signal-hot` | `#FF6A3D` | Accent pulse |
| `--brand` | `#0C9B8A` | Primary actions |
| `--paper` | `#F4F8F7` | App canvas |

## Rules

- Brand name is hero-level
- First viewport = one composition
- No cards in hero
- Motion intentional; respect reduced-motion
- RTL first, LTR only for IDs/emails
