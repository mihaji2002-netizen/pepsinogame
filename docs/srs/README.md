# PEPSINO LAB — Software Requirements Specification

This folder contains the formal specification set used to build PEPSINO LAB.

## Documents

| ID | File | Title |
| --- | --- | --- |
| 02 | [02-product-requirements-document.md](./02-product-requirements-document.md) | Product Requirements Document (PRD) |
| 03 | [03-database-design.md](./03-database-design.md) | Database Design (ERD + Database Schema) |

Document 02 is the product starting point: users, modules, flows, ID rules, non-functional requirements, MVP scope, and deliverable standard.

Document 03 is the backbone of the platform: design principles, full ERD, PostgreSQL schema for every PRD module, ledger rules for XP/Coins, progression invariants, migration order, and seed plan.
