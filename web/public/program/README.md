# قالب برنامه NEURO LAB

برای استفاده از **عکس دقیق خودتان** به‌عنوان پس‌زمینه ثابت:

1. فایل PNG یا JPG قالب را با نام زیر ذخیره کنید:
   `neuro-lab-template.png`

2. در همین پوشه قرار دهید:
   `web/public/program/neuro-lab-template.png`

3. ابعاد پیشنهادی: **3300 × 2550** پیکسل (همان نسبت قالب)

اگر PNG نباشد، از `neuro-lab-template.svg` استفاده می‌شود.

موقعیت متن‌ها در `src/lib/program/template-layout.ts` تنظیم شده‌اند و در صورت نیاز می‌توان دقیق‌تر کرد.
