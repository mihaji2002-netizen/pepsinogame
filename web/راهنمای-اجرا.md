## اعلان نتیجه آزمون در تلگرام (بدون چک کردن پنل)

وقتی دانش‌آموز آزمون را تمام کند، نتیجه مستقیم به تلگرام شما می‌آید.

### ۱. ساخت بات

1. در تلگرام به **@BotFather** بروید
2. `/newbot` بزنید و یک نام و username برای بات انتخاب کنید
3. **Token** را کپی کنید (مثل `7123456789:AAH...`)

### ۲. گرفتن Chat ID

1. به بات خودتان یک پیام بفرستید (مثلاً «سلام»)
2. در مرورگر باز کنید:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
   (به‌جای `<TOKEN>` همان توکن را بگذارید)
3. عدد `"id"` داخل `"chat"` را کپی کنید — این همان **Chat ID** است

### ۳. تنظیم در `.env.local`

```env
TELEGRAM_BOT_TOKEN=7123456789:AAHxxxxxxxx
TELEGRAM_CHAT_ID=123456789
```

### ۴. ری‌استارت سرور

```bash
npm run dev
```

از این به بعد:
- **آزمون تستی** → بلافاصله درصد و رتبه در تلگرام
- **آزمون تشریحی** → اول «ثبت شد، در انتظار تصحیح»، بعد از تصحیح نمره نهایی

## فقط سامانه آزمون برای بچه‌ها (بدون کل سایت)

در `.env.local` این خط را فعال کنید:

```env
EXAM_ONLY_MODE=true
```

بعد فقط این لینک را به بچه‌ها بدهید — **نه** آدرس اصلی سایت:

```
http://localhost:3000/exam/join
```

(روی شبکه محلی: `http://IP-لپ‌تاپ:3000/exam/join`)

| مسیر | کاربرد |
|------|--------|
| `/exam/join` | ورود دانش‌آموز + کد آزمون |
| `/admin` | فقط خودتان — ساخت و مدیریت آزمون |

با `EXAM_ONLY_MODE=true`، مسیرهای `/login`، `/student`، `/mentor` و صفحه اصلی به `/exam/join` می‌روند.

## روش ۱ — اجرا روی کامپیوتر خودتان (پیشنهادی)

```bash
git clone https://github.com/mihaji2002-netizen/pepsinogame.git
cd pepsinogame/web
npm install
cp .env.example .env.local
npm run dev
```

بعد در مرورگر باز کنید:

- **پنل ادمین:** http://localhost:3000/admin
- **رمز ادمین:** `pepsinogen1404`
- تب **✦ برنامه‌ساز** را بزنید

---

## روش ۲ — Deploy رایگان روی Vercel

1. برو به https://vercel.com و با GitHub وارد شو
2. **Add New Project** → ریپو `pepsinogame` را انتخاب کن
3. **Root Directory** را `web` بگذار
4. Environment Variable اضافه کن: `ADMIN_PASSWORD` = `pepsinogen1404`
5. Deploy

بعد از deploy آدرس شبیه `https://pepsinogame-xxx.vercel.app` می‌گیرید.
