# راهنمای اجرای PEPSINO LAB (نسخه کامل)

## چرا لینک GitHub Pages کار نمی‌کند؟

آدرس قدیمی زیر **نسخه ۲۱ تیر** است و برنامه‌ساز، آزمون آنلاین و ادمین جدید را **ندارد**:

`https://mihaji2002-netizen.github.io/pepsinogame/`

برای نسخه کامل باید روی **کامپیوتر خودتان** یا **Vercel** اجرا کنید.

---

## روش ۱ — اجرا روی کامپیوتر خودتان (پیشنهادی)

```bash
git clone https://github.com/mihaji2002-netizen/pepsinogame.git
cd pepsinogame/web
npm install
cp .env.example .env.local
npm run dev
```

بعد در مرورگر باز کنید:

- **پنل ادمین:** http://localhost:3000/admin
- **رمز ادمین:** `pepsinogen1404`
- تب **✦ برنامه‌ساز** را بزنید

---

## روش ۲ — Deploy رایگان روی Vercel

1. برو به https://vercel.com و با GitHub وارد شو
2. **Add New Project** → ریپو `pepsinogame` را انتخاب کن
3. **Root Directory** را `web` بگذار
4. Environment Variable اضافه کن: `ADMIN_PASSWORD` = `pepsinogen1404`
5. Deploy

بعد از deploy آدرس شبیه `https://pepsinogame-xxx.vercel.app` می‌گیرید.
